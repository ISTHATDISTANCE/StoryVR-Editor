StoryVR STUDY LOGGER

APPROVED STUDY

StoryVR study logger

This extension joins activity from an explicitly approved original-story page with StoryVR's interaction log. Original-story content is recorded only when the page is approved in the extension popup and Data collection is on in StoryVR.

Before a study session

  1. Use a separate Chrome profile for the study.
  2. Complete the study's informed-consent procedure. Page approval in this extension is a technical access control, not a replacement for informed consent.
  3. Open StoryVR and the original story in that same profile. Reload StoryVR once if it was already open when the extension was installed or rebuilt.
  4. On the original story, open the extension popup and review the exact origin and path shown.
  5. Confirm that the page is part of the consented study. If offered, leave visible control labels off unless that additional collection is needed and disclosed.
  6. Select Approve this story page. Approval applies only to that exact page in that tab.

Collect and save

  1. Turn on Data collection in StoryVR. Select the folder where the session data should be stored. StoryVR creates a named JSON file there; canceling the folder selection leaves collection off.
  2. Use StoryVR and switch to the approved original story as needed. A page observer records only while both approval and Data collection are active.
  3. Keep working normally. StoryVR periodically checkpoints both event streams to that JSON file so the in-memory cache stays bounded.
  4. Turn the switch off in StoryVR. StoryVR finalizes the same file in the selected folder without opening a second location chooser.
  5. If a checkpoint or finalization fails, StoryVR retains the unwritten data for a retry. Successful finalization clears the remaining cache and all original-page approvals.

Page approval boundary

Any top-level HTTP or HTTPS original-story page can be approved through the popup. Approval is temporary and limited to the current tab, exact origin, and exact path. Query strings and fragments are not part of the saved page identity.

A reload of the same page keeps approval. Approval is removed when the tab moves to another path or origin, closes, is explicitly revoked, the session is successfully finalized, or the extension or browser restarts. A new or duplicated tab must be approved separately.

Only the top-level page is observed. Content inside any embedded frame is not captured.

What is collected

While both gates are active, the extension can record clicks, safe control kinds, coarse pointer and scroll buckets, page visibility and focus, and switches between approved pages or other tabs. An outside tab produces only a generic tab-switch event; its address and content are not read.

Visible text on clicked controls is excluded unless the separate optional control-label choice is shown and selected during page approval. It may contain sensitive text and should be enabled only when the study requires and discloses it.

The extension does not record typing, form values, keystrokes, cookies, page storage, query strings, full or raw URLs, browsing history, or raw Chrome tab identifiers. The temporary cache uses session-only extension storage. StoryVR writes approved data only to the named JSON file in the folder selected when collection starts; it does not upload it.

Remove page access

Open the extension popup on an approved original story and select Stop observing this tab. Recording from that page stops immediately. StoryVR's Data collection switch controls the full logging session.
